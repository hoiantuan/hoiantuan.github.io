MCP: AIのためのUSBポート

初期状態でも、Claudeはファイルの読み書き、ターミナルコマンドの実行、URLのブラウジングなどを行うことができます。しかし、会社のデータベースを検索したり、ブラウザを高度に制御したり、社内APIを呼び出す必要がある場合はどうでしょうか？

そこで役立つのがMCP サーバーです。これはUSBポートのような役割を果たし、接続するだけでClaudeに新しい機能を与え、取り外せばその機能が消えます。

.mcp.json (実際の設定ファイル例) 
{
  "mcpServers": {

    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp"]
    },

    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
解説

mcpServers — これによりClaudeへ外部機能接続を追加します。各エントリーは起動設定を持つ名前付きサーバー群です。

playwright — Claudeに実際のウェブブラウザを制御する能力を与えます。ボタンをクリックしたりスクレイピングなどが可能になります。

context7 — ドキュメントデータベースや外部情報などにアクセスするためのシステム連携機能。

全機能の連動：コマンド → エージェント → スキル

これで5つのモジュールすべてがどのようにつながるかが分かります。入力から最終的な図の出力までの完全な天気取得ワークフローを見てみましょう。
