The difference is programmability

### Weather System
A demonstration of the
Command → Agent → Skill
architecture:
- `/weather-orchestrator`
  command: Entry point
- `weather-agent`
  agent: Fetches temperature
- `weather-fetcher`

PLAIN ENGLISH

## Key Components — This section header tells Claude "here are the important moving parts of this project."

Weather System — This particular example shows how a command, agent, and skill work together as a team.

/weather-orchestrator — When you type this slash command, it kicks off the whole workflow.

weather-agent — An autonomous worker Claude can spawn to fetch the actual data.

weather-fetcher skill — A reusable set of instructions preloaded into the agent so it knows how to call the weather API.
