Commands & Skills

Your automation vocabulary — recipes and knowledge cartridges

Commands: keyboard shortcuts for entire workflows

Imagine you're a chef. Instead of explaining the entire risotto recipe every time someone asks for it, you just say "make the risotto." The recipe is already written down — you're just invoking it by name.

That's a command. It's a .md file full of instructions Claude follows when you type /its-name. Write it once, use it forever.

📁
Where commands live

Commands go in .claude/commands/ inside your project. Each file becomes a slash command — the filename is the command name.

Anatomy of a command

Here's a real command from the repo — the weather orchestrator. Let's read it line by line.

weather-orchestrator.md 
---
description: Fetch weather for Dubai
model: haiku
---

## Workflow

### Step 1: Ask User Preference
Use AskUserQuestion to ask
whether they want Celsius
or Fahrenheit.

### Step 2: Fetch Weather Data
Use the Task tool to invoke
the weather-agent...

### Step 3: Create SVG Card
Use the Skill tool to invoke
weather-svg-creator skill.
PLAIN ENGLISH

description: A one-line summary of what this command does. Claude reads this to know when to suggest it.

model: haiku — Use the faster, cheaper model for this command. You can override the model per command.

Step 1 — First, ask the user a question before doing anything. This makes the workflow interactive.

Step 2 — Spawn a specialized subagent (weather-agent) to go fetch the actual data. The command orchestrates; the agent does the work.

Step 3 — Load a skill (weather-svg-creator) to generate the visual output. Each step hands off to the right specialist.

Skills: knowledge cartridges you snap in

A skill is like a removable memory chip. It contains specialized knowledge — instructions for a specific task — that gets loaded into Claude's context when needed, and removed when it's done.

The key idea: instead of one giant brain that knows everything, you have a lean base plus skill files you snap in on demand.

📦

Agent Skills

Preloaded into a subagent via its skills: field. The agent always has this knowledge available.

🛠️

Invocable Skills

Triggered via Skill(skill: "name"). Claude loads the skill, follows its instructions, then continues.
