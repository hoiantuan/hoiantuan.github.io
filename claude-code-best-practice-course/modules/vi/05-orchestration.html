MCP: Cổng USB giao tiếp cho AI của bạn

Hàng mặc định gốc, Claude có thể đọc và ghi, chạy phím terminal, tìm web URLs. Nhưng lỡ mà bạn muốn bắt nó tìm kiếm Data trong Database kín, khống chế một trình duyệt, hay gọi một API bảo mật của công ty mình thì sao?

Đó là lý do MCP servers ra đời. Cứ thử hiểu nó như cổng USB: cắm vào là máy nhận sức mạnh mới. Rút khỏi máy thì bay năng lực.

.mcp.json (cấu hình thực) 
{
  "mcpServers": {

    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp"]
    },

    "context7": {
      "command": "npx",
      "args": ["-y", "@upstash/context7-mcp"]
    }
  }
}
GIẢI THÍCH ĐƠN GIẢN

mcpServers — Liệt kê thông số các năng lực gắn vào Claude. Tùy mỗi cấu hình mà năng lượng kết nối của Server khác nhau.

playwright — Cấp cho Claude siêu năng lực kết nối trực tiếp thao tác thẳng Web (bấm chuột ảo, chụp màn hình ảo v..v).

context7 — Kết nối dữ liệu vào các cỗ máy Data nội bộ hoặc API.

Toàn cảnh cấu trúc: Lệnh → Đặc vụ → Kỹ Năng
